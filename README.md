# gestion-pagos.java
# Gestión de Pagos de Servicios

Aplicación de consola en Java que permite gestionar facturas de servicios y sus pagos. Es el trabajo integrador de Programación Básica I de la Tecnicatura Universitaria en Desarrollo Web (UNLaM), realizado en equipo.

## Qué hace

- Registra facturas de servicios con su estado de pago.
- Realiza la búsqueda de facturas por número.
- Obtiene las facturas que fueron pagadas por un método de pago especifico.
- Ordena las facturas pagadas con monto menor a un valor dado, de mayor a menor, usando el método de ordenamiento burbuja.
- Obtiene la cantidad de facturas pagadas ingresando un servicio.
- Obtiene el promedio de pagos realizados.
- Obtiene el monto máximo pagado.

## Estructura del proyecto

- `Factura`: representa una factura de servicio.
- `GestionPagos`: contiene la lógica para administrar las facturas.
- `PruebaGestionPagos`: clase con el `main` para probar la aplicación.
- Enums: contiene los servicios, métodos de pago y estados de las facturas. Además de gestionar el menú principal de la aplicación.

## Cómo ejecutarlo

1. Clonar el repositorio: `git clone https://github.com/PeterMLucas/gestion-pagos-java.git`
2. Abrir la carpeta `src` en Eclipse (o cualquier IDE de Java).
3. Ejecutar la clase `PruebaGestionPagos`.

Requiere Java 21
